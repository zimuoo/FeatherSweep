## 轻扫 · FeatherSweep 1.2.0

现在同时支持 **Apple Silicon（M 系列）与 Intel**，每个安装包约 **2.4 MB**，系统要求 macOS 14+。

### GitHub 自动更新

- 默认启动时及每 6 小时检查正式版本，自动下载对应架构的安装包。
- 使用 Sparkle 2.10.1，验证 Ed25519 签名后安装；签名订阅与安装包均已校验，发布私钥只保存在本机钥匙串。
- 扫描或清理未结束时等待，空闲后自动安装并重启；已暂存、等待重启的更新同样受到退出保护。
- 菜单栏增加 **检查更新…** 和 **自动下载安装更新** 开关，设置会保留。
- 更新访问 GitHub 及其下载服务，不上传扫描数据、文件内容、聊天或密码，不发送系统配置报告。演示、截图和只读扫描模式不启动更新。

**1.1.0 及以前没有更新器，需要手动安装一次 1.2.0。** 打开 DMG，把「轻扫.app」拖入 Applications 后运行；之后按项目发布流程提供的正式版本可自动更新。

两个版本均使用本机 ad hoc 签名，尚未 Apple Developer ID 公证。需要管理员授权时使用标准 macOS 授权流程，不要求关闭 Gatekeeper。

### 验证

- arm64 与 x86_64 各 **82 项测试通过，0 失败、0 跳过**，包含原生菜单、更新开关、实际委托回调、忙碌安装与退出保护。
- 两个 DMG 的架构、最低系统、框架加载、签名、挂载与演示运行通过。Intel 通过 Rosetta 2 验证，尚未在实体 Intel Mac 上测试。
- 实际签名下载与安装测试在独立标识的临时应用副本上完成，版本从 2 替换至 3，与更新包应用一致；未替换用户安装的应用。
- 修改过的订阅内容或 DMG 均无法通过签名验证。

下载对应 DMG 和 [SHA256SUMS](https://github.com/zimuoo/FeatherSweep/releases/download/v1.2.0/SHA256SUMS)，比对同名文件校验值；若同时下载两个 DMG，可运行：

```sh
shasum -a 256 -c SHA256SUMS
```
