# 轻扫

已获用户批准的 UI：浅色原生小窗口，两个主要操作“查看垃圾”“清理垃圾”，扫描环、数字过渡、清理粒子与完成状态。新增要求：独立软件 Logo、菜单栏常驻、体积小的 DMG 安装包。

## 实现边界

- SwiftUI + AppKit，macOS 14 以上，优先本机 Apple Silicon，无第三方运行时。
- 首页真实扫描后才允许清理；明细可展开查看路径、原因、数量和大小。
- 关闭窗口转入菜单栏，菜单支持打开、扫描、清理及退出；繁忙时避免重复任务。
- 绘制蓝色磁盘与清洁星芒矢量 Logo，生成各尺寸 AppIcon.icns；菜单栏使用单色模板图标。
- 只匹配已经人工验证的目录与格式：Go 构建缓存、指定 Rust 中间目录、Cursor 快照、yisora 打包解压副本及有相同保留文件的重复安装包、过时更新下载、Chrome 闲置应用签名副本、飞书/Cloudflare 静态缓存。
- Blender 每个场景保留最近修改的 1 份备份；不会删除场景最后一份备份。
- 所有浏览器密码、Cookie、登录与网站持久化数据、源码、正式发布安装包、有效模型及 SDK 均排除。
- 仅扫描不写数据；清理前重新校验文件身份、目录元数据指纹（重复安装包另作内容 SHA-256 校验）、占用进程与保留副本；拒绝符号链接路径逃逸。文件变化、使用中或无权限时跳过并显示原因。
- 原生文件描述符删除，不执行 shell/rm，不申请 root。清理日志有上限。对共享签名副本只显示份数，避免把 APFS 共享数据误算成可回收的 TB。
- UI 演示模式只模拟显示；真实扫描只读；集成清理仅在测试临时目录执行。
- DMG 包含 app 和 Applications 快捷方式。本机临时签名；无 Apple Developer 凭证时不声称已公证。
