# FeatherSweep 1.2.0 — Intel 与签名自动更新

用户已要求增加 Intel 安装包，并在 GitHub 有新版时自动下载安装。沿用已批准的小窗口与菜单栏，不改变垃圾清理选择和凭据保护规则。

## 行为

- 提供 arm64 与 x86_64 两个原生 DMG，均要求 macOS 14+。
- 启动时及每 6 小时检查 GitHub 最新正式发布的对应架构 appcast；默认自动下载、验证、空闲时安装并重新启动。用户可在菜单栏关闭自动更新，也能手动检查。
- 扫描或清理过程中不得因自动或手动更新重启。下载与验证可在后台进行，安装就绪后保留回调，任务结束后只执行一次。
- 演示模式、截图、只读扫描和普通 SwiftPM 可执行文件不启动更新器。
- 不绕过 macOS 权限、签名或 Gatekeeper；系统需要管理员授权时由标准更新器请求。不能写入的应用或 DMG 中运行的应用显示标准安装提示。

## 安全与体积

采用固定版本 Sparkle 2.10.1，使用 HTTPS、Ed25519 签名归档、验证后解压及已签名 feed。不自己实现应用替换或权限提升。发布私钥仅保存在本机登录钥匙串，不进入代码、GitHub 或安装包；公钥随应用发布。更新仅接受本仓库 GitHub Release 路径。禁用系统配置收集，不上传扫描数据、文件内容、密码或聊天。

框架增加少量安装体积；两架构保持独立压缩，发布前记录实测体积并修正文档。不再把新版本宣传为没有第三方框架或完全不联网。项目保持“源码公开”，不添加项目 LICENSE；附上 Sparkle 自身许可。

## 发布与验证

保持 v1.1.0 和原 arm64 安装包不变，1.2.0 同时发布两个新包、SHA256SUMS 和两个签名 appcast。发布脚本从本机钥匙串签名，无私钥明文导出。后续每次通过脚本发布正式版本，客户端即能识别和自动更新。

测试覆盖：忙碌时延迟安装、空闲恢复一次、关闭自动更新、手动更新继续受忙碌保护、演示和开发构建不联网、feed 与下载 URL 限定；两架构编译、原有清理测试及原生菜单测试；DMG 架构、最低系统、框架加载、签名、只读挂载、Ed25519 签名有效与篡改拒绝。使用临时应用副本测试真实更新，绝不替换用户已安装应用或清理真实文件。Intel 包通过 Rosetta 验证，明确尚无实体 Intel Mac 实测。
